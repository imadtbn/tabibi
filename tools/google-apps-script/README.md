# ربط نموذج طبيبي بـ Google Sheets

ملف المراجعة: https://docs.google.com/spreadsheets/d/1FXerDOnLHokGICOeRt2RKfTdQZNMcfhOE5YiN_5CT_c/edit

1. افتح الملف بالحساب المالك، ثم اختر **الإضافات > Apps Script**.
2. استبدل محتوى `Code.gs` بمحتوى الملف المجاور `Code.gs` واحفظه.
3. اختر **نشر > عملية نشر جديدة > تطبيق ويب**.
4. التنفيذ باسمك، والوصول: **أي شخص**؛ ثم انسخ رابط `/exec`.
5. ضع الرابط في `js/submission-config.js` داخل `SUBMISSION_ENDPOINT`، ثم أعد البناء والاختبارات وارفع التحديث.
6. أرسل طلب اختبار واحدًا من صفحة إضافة الطبيب، ورسالة اختبار من صفحة التواصل، وتأكد من ظهورهما في Google Sheets. نموذج التواصل يستخدم إرسال HTML تقليديًا لتجنب مشكلة CORS في Google Apps Script.

## دورة المراجعة والنشر

- غيّر حالة السجل إلى **مقبول** بعد التحقق، أو **مرفوض** مع ملاحظة.
- من قائمة **طبيبي** داخل Google Sheets اختر **تصدير ملفات JSON المعتمدة**.
- سيُنشأ مجلد في Google Drive يحوي ملفًا كاملًا لكل اختصاص.
- استبدل الملفات المناظرة داخل `data/doctors/`، ثم شغّل:

```bash
python3 tools/build.py
npm test
```

لا تجعل ملف Google Sheets عامًا للتحرير. تطبيق الويب هو قناة الإدخال الوحيدة للزوار، والملف يبقى خاصًا بالمراجعين.
